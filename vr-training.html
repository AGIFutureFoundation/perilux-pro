The VR training

A dental clinic you can practise in, in your browser

The Unspoken Smiles VR Training prototype is a browser-based 3D dental clinic where learners practise dental assisting, hygiene support, and school screening before ever touching a patient: structured sessions, immediate feedback, and a coach-readable record. It was built by the AGI Future Foundation for the NemulAI × Hack District “Zero to Demo” hackathon, Impact track.

▶ Open the live demo  Read the code

Live demo verified 2026-11-11: the GitHub Pages site loads and opens the app. No install, no account, no headset needed. The app is a single large page — give it a moment on a slow connection. Nothing is saved: progress lives only while the page is open, and resets on reload, by design.

Prototype — demo only. This is a demo program inspired by Unspoken Smiles' public work. It is not an official Unspoken Smiles program, not endorsed by or affiliated with Unspoken Smiles. No partnership, pilot, or contact is claimed. It is not a licensure, certification, or clinical-training product: simulation is not certification, and VR practice does not count as clinical hours. Cases are fictional; the app holds no patient data.

How it runs today — stated plainly

  • Magic-window view. The training runs in a desktop or mobile browser view — mouse and touch, no headset, no controllers. This is how it actually runs now.
  • “Check headset” is a check, not a session. The in-app button only reports whether your browser and device support an immersive-vr WebXR session. It starts no session, and no Quest hardware test has happened. A real WebXR session is Phase 4 work, not yet built.
  • No recorded walkthrough video yet. A timed 120-second storyboard and a narrated voiceover track exist; the recording itself is still to be made.
  • Badges stay private. A graded finish can earn a badge shown only on the page, for learner and coach. Never public, never a completion record.
  • Transfer is never marked done. Every Simulation Studio run carries “Simulation ≠ certification”, and transfer to a real setting is never recorded as complete inside the simulation.

Under the hood, the clinic applies Meta Immersive Web SDK (IWSDK) architecture patterns — grab, locomotion, spatial UI, dual runtime — over vendored Three.js, and says so in its own documentation rather than claiming the full scaffold. The six-station blueprint and seven-step progression behind it are on the Stations page.
