Prevention & School Screening

The flagship session — the one session fully playable end to end in the VR clinic. It follows the Zero Cavity workflow — screen → educate → refer — with no treatment in the field. A live checklist highlights the current step throughout, a short theory card precedes each step, and the sequence itself is the lesson: in a graded run, out-of-order actions are recorded as sequence faults with a stated consequence.

The rules the session teaches

  • Consent comes before screening, every time. No form, no screening — no exceptions. A child without a signed form joins the brushing demo group while the consented children are screened.
  • Screening is not diagnosis. See a dark spot? Record what you see and flag it — the clinician decides what it is.
  • Privacy first. Screens go up before the kit comes out; the kit is laid out in the same order every time.
  • Comfort is part of the skill. An anxious child is met at her level, shown the big tooth first, and given a stop signal — and if she still says no, she joins the demo unscreened, and it is noted, kindly.
  • The record is part of the care. The morning closes when the charts, the flags and the log agree.

Scoring — play only

Each run goes lesson → checklist → tasks (50 points) → visual quiz (100 points), rated Bronze <40% / Silver <70% / Gold <95% / All-Star 95%+. The rating is play only — never a credential or a completion record. In the TradePath Training Centre, the same session runs as a five-step guided scenario: PPE and referral-path check → welcome and consent → set screens and kit → run the screening steps → close the queue, file the forms, debrief with the coach.
