Stack & programme support

Perilux is built and run on the same production stack as the rest of the agentic network. This page lists the vendors we build on and the startup programme support we can name and verify. Programme support means credits and services we actually use — nothing on this page is an endorsement in either direction, and no vendor listed here is claimed as an official partner.

Programme support we can verify

Analytics

PostHog

PostHog for Startups — $50,000 in programme credits. Analytics are live across all estate sites, in six PostHog projects.

Error monitoring

Sentry

Sentry for Startups — $5,000 in credits. Error monitoring is live on eight projects across the network.

Data

TiDB Cloud

PingCAP startup programme — $500 in credits, with a live TiDB Cloud cluster running.

Speech

Deepgram

Speech-to-text for the network's audio work — $200 in startup credits.

Model routing

OpenRouter

Programme credits; OpenRouter routes model calls for the agent fleet.

Hosting

Railway

Hosting credits supporting network services.
